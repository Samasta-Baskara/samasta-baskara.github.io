Under the hood

Six pieces, one pipeline.

What actually powers a scan, from the network layer to browser-based verification.

⌘

Async network engine

Python AsyncIO plus HTTP/2 via httpx, with host rate-limiting and a circuit breaker for thousands of concurrent requests.

◎

TLS impersonation

JA3/JA4 fingerprint spoofing via curl_cffi, so traffic presents as a real browser to anti-bot defenses and WAFs.

⌁

Go native bridge

Hands fuzzing straight to Go binaries — subfinder, httpx, katana, nuclei, dalfox, gau — for native throughput.

▣

Playwright verification

Ten browser-based modules confirm findings live: DOM XSS, CSRF, postMessage leaks, clickjacking, and more.

≡

Tactical TUI dashboard

A three-column terminal view refreshed at 15 FPS: pipeline stage, request-rate sparkline, and finding severity.

✓

Policy & audit engine

Scope locks, request budgets, and a replayable .jsonl audit log that reconstructs every request as curl.

A practical pipeline

Recon, then app analysis, then assault.

Verdamt-Snipe runs seven scan modes on top of one pipeline, from passive intelligence gathering to a full vulnerability assault. The repository README is the source of truth for current flags and behavior.

  • Start with --dry-run to validate payloads without sending traffic.
  • Use --passive to restrict requests to GET, HEAD, and OPTIONS.
  • Review the .jsonl audit log, replayable as curl for reporting.
Usage examples
# interactive TUI launcher
./snipe target.com

# full pipeline, stealth + SOCKS5 proxy
./snipe 5 target.com -s -p socks5://127.0.0.1:9050

# resume an interrupted scan
python3 verd.py --resume outputs/target.com.state

Getting started

Three steps to a working install.

Requires Linux or macOS, Python 3.10+, and 2 GB+ of memory. Commands below match the current README.

git clone https://github.com/Sambaskara/Verdamt-Snipe.git
1
Clone the project

Get the source from GitHub using one of the methods above.

2
Set up a virtual environment

Install dependencies inside an isolated environment:

python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
3
Install the Playwright driver

Required for the browser-based verification modules:

playwright install chromium

Tap a step to mark it done · 0 of 3

Use Verdamt-Snipe only on systems you own or have explicit authorization to test — a bug bounty program or a signed penetration-testing agreement. Always stay within scope.
